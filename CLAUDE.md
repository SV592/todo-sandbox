# todo-sandbox

This repo is a test target for agent-review. Keep `main` as a clean base branch.

- Never commit directly to `main`. Before making changes, create a feature branch off an up-to-date `main` (`git checkout main && git pull && git checkout -b <short-description>`).
- Commit work on that branch; agent-review only sees committed changes on a branch compared against `main`.
- Do not merge into `main` or push to it unless explicitly asked.
